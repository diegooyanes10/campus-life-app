# Campus Life App

An app of events and dining for grace college students.

## Technologies

Used HTML, CSS, Bootstrap, JavaScript, Open Meteo API

## Features

- Home: weather + picture of the college + quick links
- Events: searchable event list
- Dining: menu selector with hours

## Usage

Just open the home page (index.html), and then you can search events, pick dining hall, check weather in the campus.

## Deploy

To publish the app online:

1. Push the code to GitHub:
git push origin main

2. Enable GitHub Pages: Go to your repository Settings, then Pages, and select main branch as source.
